The Ascent Verify API lets your server's own tools check who has verified with Ascent in your server.

**Base URL:** `https://api.ascentverify.xyz`

## Authentication

Every request needs an API key, sent as a Bearer token:

```bash
curl https://api.ascentverify.xyz/v1/server \
  -H "Authorization: Bearer asc_live_xxxxxxxxxxxxxxxxxxxxxxxx"
```

Server owners, and staff with **Control Modules**, create keys on the server's **API** page on ascentverify.xyz. A key is shown only once when it's created, so copy it then. Each key belongs to one server and only returns data for that server. A server can have up to 5 keys. Each key lasts 30, 90 or 365 days, or never expires, chosen when it's made. Make a new key before an old one runs out.

Keep keys secret. Use them from your own server or bot, never in a web page or app that other people can open.

## Privacy

A key can only see members who have verified in its server or sent their Ascent card to it. Looking up anyone else returns `404`, the same as a Discord ID that has never used Ascent, so a key can't be used to check strangers.

## Rate limits

Limits are per key, set by the server owner's plan. Every response includes these headers:

| Header | Meaning |
| --- | --- |
| `X-RateLimit-Limit` | Requests allowed per minute |
| `X-RateLimit-Remaining` | Requests left this minute |
| `X-RateLimit-Reset` | Seconds until the limit resets |

Going over the limit returns `429` with a `Retry-After` header.

## Errors

Errors return JSON with a machine-readable `error` code and a plain-language `message`:

```json
{ "error": "not_found", "message": "No member with that Discord ID has verified in this server." }
```

| Code | Status | Meaning |
| --- | --- | --- |
| `bad_request` | 400 | Something in the request isn't valid. |
| `unauthorized` | 401 | The API key is missing, wrong, revoked, or expired. |
| `not_found` | 404 | No matching member in your server. |
| `rate_limited` | 429 | Too many requests. Wait for `Retry-After` seconds. |
| `server_error` | 500 | Something went wrong on our side. |
