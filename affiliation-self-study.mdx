title: "Affiliation Self-Study"
---

We encourage servers who wish to affiliate with us to complete this optional self-study first to ensure that they meet our basic requirements for affiliation. For each row, read through the description of what it means to be in compliance and determine where you fall, you must be compliant in all five categories before affiliating.

|  | Compliant | Compliant? | Steps Needed |
| --- | --- | --- | --- |
| Aesthetic and Functional Design | Server follows a brand guide or similar to ensure that all designs, websites and graphics produced follow a similar level of care. In addition, all designs go through a quality control process if necessary to ensure they meet the standards set in place by the server. |  |  |
| Working Program/Software | Server has reviewed all functionality of custom website and bot and has thoroughly tested it. No bugs are present and the code is polished. In the unlikely event of an error, they are handled gracefully and display a user-friendly error message to the user. |  |  |
| Verification Status | Server has an active Ascent Verify account that has not been banned or removed and the Ascent Verification bot is still present in the server. |  |  |
| Response Times | Server ensures that all support tickets, orders and paid ads are reviewed in a reasonable amount of time. There may be outliers, but for the most part the wait time fall within a normal distribution with a mean of the following:<br /> **Orders:** Initial contact within 5 hours, Order completed/Ad scheduled within 3 days **Support Ticket:** Initial contact within  3 hours, issue resolved within 2 days<br /><br />Server has necessary documentation from their support ticket provider to back up this statement. |  |  |
| Server Setup | Server has channels grouped in categories that make sense, it is easy to find information such as support and server rules. Each channel has it's own purpose and there are no unused/duplicate channels. |  |  |
